# About

This documentation is intentionally public and open source.

The full source is available on GitHub, so in principle anyone can contribute, maintain content, and help carry the documentation forward over time.

## Why this exists

The long-term goal is to build a music pipeline that enables meaningful public and community collaboration for *Night of the Meteor*.

That requires more than style notes and file specs. It also requires shared infrastructure, clear process, and transparent onboarding paths.

## Long-term direction (planned)

One planned step is a central, community-facing place for music tasks. A comparable list currently exists only internally.

The intended public version would help contributors:

- see what work is currently needed
- access required assets in a spoiler-safe way
- coordinate with leads before and during production
- deliver assets in a format that is integration-ready

## Spoiler handling

To protect narrative content, scene spoilers should only be shared directly when contributors are actively coordinating with project leads.

The public workflow should stay as open as possible while still protecting unreleased story details.
